# 小程序上架文案（定稿）

> 给微信公众平台后台填表用。每一项都标了字数上限和当前字数，改之前先对一遍。

## 一、字数规则（先看这条，否则会被反复打回）

微信后台的「字符」不等于「汉字」：

| 项目 | 规则 | 实际能写多少汉字 |
| --- | --- | --- |
| 简介 | 4–120 字符，**一个中文占 2 字符** | **最多 60 个汉字** |
| 名称 | 4–30 字符，一个中文占 2 字符 | 最多 15 个汉字 |
| 简称 | 4–10 字符 | 最多 5 个汉字 |

标点也算字符，全角标点按中文算（2 字符），半角数字和字母按 1 字符算。

**一个月内只能改 5 次简介**，名称改 2 次。所以名称、头像、简介、类目建议一次全定好，别来回试。

## 二、小程序简介（定稿 · 110 字符 / 55 汉字位）

```
填货值、运费和目的国，算两个数：这批货到手花多少钱，报关那几天账上要备多少。算不准的会列出来，不硬凑一个数字。
```

**为什么是这几句：**

- 开头三个词就是输入，用户 3 秒内知道要填什么
- 「算两个数」是本产品的核心结构——`landedCost` 与 `cashRequired` 分开算、永不相加
- 结尾「算不准的会列出来，不硬凑一个数字」是真实能力（待核清单 + 出处置信度），不是口号。**这句不能删**，它是和「随便报个价」的同类工具唯一的区别

**可选微调**：若担心「报关」二字引起类目联想，把「报关那几天」换成「到港那几天」，语义不变，字符数也完全一样（都是 5 个汉字），仍是 110 字符。

```
填货值、运费和目的国，算两个数：这批货到手花多少钱，到港那几天账上要备多少。算不准的会列出来，不硬凑一个数字。
```

## 三、提交审核时的「功能介绍」

这一栏**不要重复简介**。审核员看它判断「类目与实际功能是否相符」，要写成说明书，并明确说不采集个人信息。

当前 484 字符（约 240 汉字）。后台这一栏比简介宽松，但如果提示超长，优先删第二段中间「不上传通讯录、位置或相册」这半句，别删第一段的功能清单——审核看的是功能清单。

```
本小程序为外贸进口成本测算工具，输入商品编码、货值、运费与目的国，输出「真实成本」与「需备现金」两个独立金额，二者不相加。另提供待核事项清单（标注算不准的原因与所需补充资料）、政策变动日历、外贸知识视频索引（跳转外部链接观看）、以及基于公开关税规则的问答助手。

全部计算在服务端依据公开税率表完成，结果仅供参考，不构成报关或法律服务。不采集用户身份信息，不上传通讯录、位置或相册，仅记录匿名设备标识用于保存本人历史测算记录。无内购、无广告、无用户间交易。

服务类目：工具 — 信息查询。
```

最后那句「结果仅供参考，不构成报关或法律服务」建议保留，它能挡掉「你凭什么替我报价」这类质疑。

## 四、禁用词（写了会被要资质、会卡审）

| 不要写 | 原因 |
| --- | --- |
| 代理报关、清关服务、代办通关 | 触发《报关企业注册登记证》资质要求 |
| 包税、保证通关、准确率 100% | 承诺性表述，审核会要求举证，且我们做不到 |
| 官方、权威、最准、第一 | 绝对化用语，广告法与平台规则都禁 |
| 海关推荐、政府合作 | 不能凭空写合作方 |
| 砍价、集赞、分享解锁 | 诱导分享，微信处罚很重（轻则限制分享能力） |

**「报关」单独作描述是安全的**（如简介里的「报关那几天」只是时间节点）。危险的是「提供报关服务」这种业务主语。

| 头像 | `out/icon/icon-512.png`（满幅方图，不要自己切圆角） |

关于「不收集个人信息」的口径：后端确实只存 `did`（浏览器或小程序端生成的随机串），不存手机号、微信号、姓名、位置。所以这个声明是真实的，不是掩盖。
