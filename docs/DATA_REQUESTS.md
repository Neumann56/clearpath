## 一、P0 · 会算错钱，且用户看不出来

### P0-1 清关杂费（44 个市场全缺）

**要什么**
每个市场的进口环节固定规费：报关费、码头操作费（THC）、单证费、检验费、系统使用费等。

| 字段 | 说明 | 例（美国 MPF） |
| --- | --- | --- |
| 规费名称 | 当地官方叫法 | 商品处理费 Merchandise Processing Fee |
| 计算方式 | 从价% / 按票固定 / 按重量 / 按柜型 | 从价 0.3464% |
| 上下限 | 有最低最高额的必须给 | 最低 33.58 / 最高 651.50 美元 |
| 计费基数 | CIF / FOB / 运费 / 申报货值 | 申报货值 |
| 是否进完税价格 | 影响关税基数（巴西 AFRMM 属于这类） | 否 |
| 生效日 + 出处链接 | 费率会调，必须能追溯 | cbp.gov |

**为什么必须补**
现在 44 个市场的规费**恒为 0，而且报告里一个字都不提**。我实测过：同一个国家，如果参数里有规费定义（如美国），报告会说"本报告未计入规费，若计入将增加 XXX 美元"；如果参数里压根没有定义（欧盟、东南亚全部如此），报告当它不存在，直接出到岸成本。

结果就是：**欧盟、东南亚的到岸成本系统性偏低，而报告看不出来。** 典型一票（FOB 4.8 万）规费大约 150–400 美元，占货值 0.3–0.8%。

> 这一条我另外会改代码，让"该国规费未入库"进报告的缺口清单，不再沉默。但数据还是得有人给。

**参考起点**：欧盟各国差异不大（报关代理费 + 码头费通常 80–200 欧元/票），东盟差异大（印尼有 PIB 系统费、越南有 VNACCS 费用、菲律宾有报关行固定费）。

### P0-3 欧盟 5 个品类的 8 位子目（现在只有汽配）

**要什么**
欧盟 27 国共用一套 TARIC，所以**做一遍就够 27 国用**。现在是：

| 品类 | 6 位税率 | 8 位子目 | 状态 |
| --- | --- | --- | --- |
| 870891 汽车零件 | 3% | 20=3% / 35,91=4.5% / 99=3.5% | ✓ 已建（81 条） |
| 847130 笔记本电脑 | 0% | — | 需确认是否全零 |
| 851713 智能手机 | 0% | — | 需确认是否全零 |
| 854143 光伏组件 | 0% | — | 需确认是否全零 |
| 610910 针织 T 恤 | 12% | — | **子目差异可能很大** |
| 940360 木制家具 | 0% | — | 需确认是否全零 |

**优先做 `610910`**：服装是欧盟子目差异最大的品类（棉制/合成纤维、男装/女装、针织/梭织分开计），6 位取 12% 很可能差好几个点。其余 4 个品类多半是零关税，确认一下就行。

**为什么必须补**
汽配那一条已经证明差异真实存在：6 位取 3%，实际子目有 4.5%（8708 91 35/91）。**录 6 位和录 8 位会得出不同金额**，而大多数用户只会录 6 位。

## 二、P1 · 报告会漏说，用户以为"没事"

### P1-1 认证要求（17 个国家一条都没有）

**要什么**
每个市场进口时强制要求的产品认证 / 注册 / 标识，以及**办理周期**。

现在只有欧盟有 4 条（GPSR、EPR、产品责任险、E-mark 汽配认证）+ 沙特 SABER。

**完全没有的 17 国**：印度、英国、瑞士、挪威、塞尔维亚、乌克兰、俄罗斯、日本、韩国、新加坡、泰国、越南、马来西亚、印尼、菲律宾、孟加拉、巴基斯坦

**东盟最常撞的几个**（请优先）
| 国家 | 认证 | 要点 |
| --- | --- | --- |
| 印尼 | SNI 强制认证 | 哪些品类强制、周期多久（现有参数写 12–24 个月，疑偏长，实际常见 3–9 个月） |
| 越南 | 能效标识 / QCVN | 电子、汽配是否在范围内 |
| 泰国 | TISI | 哪些品类强制 |
| 马来西亚 | SIRIM / ST | 电子类 |
| 菲律宾 | PS / ICC 标志 | 哪些品类需 PS |
| 新加坡 | Safety Mark | 受管制电器清单 |

**为什么必须补**
报告第 8 段是"什么时候办什么证"。对东南亚的单子，这一段现在是空的——用户会以为"不用办证"，实际是"我们没数据"。**交期排错的代价比钱大**：认证 45–120 天，货做完进不去等于压库存。

**交付要求**：认证名称（中文 + 当地缩写）、是否强制、适用品类、办理周期（天）、办理方（出口商 / 制造商 / 进口商）、官方链接。

### P1-2 自贸协定优惠税率（东盟缺 3 品类，日韩全缺）

**要什么**

| 协定 | 覆盖 | 现状 | 缺 |
| --- | --- | --- | --- |
| 中国—东盟 AIFTA | 越南、泰国、马来、印尼、菲律宾、新加坡 | 3 个品类已建（汽配、T 恤、家具 → 0%） | 笔电、手机、光伏 3 个品类 |
| RCEP | 中日韩澳新 + 东盟 | **0 条** | 日本、韩国全部品类 |
| 中国—瑞士 FTA | 瑞士 | 0 条 | 全部（手表/精密件为主，工业品可能已零关税） |
| 中国—塞尔维亚 FTA | 塞尔维亚 | 0 条 | 2024 年生效，值得建 |

**日韩为什么值得做**：日本汽车零件 MFN 现在是 0%，但如果拿的是 RCEP 或没有优惠，实务上要注意原产地规则；韩国汽配 MFN 8%，RCEP 下分年降税，**这是真金白银的差**。

**交付要求**：每个协定 × 每个品类给
- 优惠税率（%）
- 需要的原产地证书名称（Form E / RCEP 原产地证 / Form RCEP）
- 区域价值成分门槛（RVC，通常 40%）
- 是否分年降税（如果是，给 2026 年这一档）
- 敏感清单例外

> **注意**：优惠税率**不会自动进到岸成本**。有没有原产地证是用户手上的事实，系统只回答"如果办证能省多少"。所以这块数据不补，产品不会算错，只是少一个卖点。

### P1-3 反倾销 / 保障措施（只有 3 条）

**要什么**：中国出口到这三个区域、正在生效的贸易救济措施。

现在只有：印度对华太阳能电池（30%）、土耳其对华光伏组件（25 美元/㎡）。

**优先核查的**
| 目标市场 | 措施 | 状态 |
| --- | --- | --- |
| 欧盟 | 对华电动车反补贴税 | 是否有？税率多少？是否覆盖汽配 |
| 欧盟 | 对华钢铁保障措施 | 汽配是否间接受影响 |
| 印尼 | 保障措施（纺织、部分机电） | 是否覆盖 T 恤/家具 |
| 越南 | 对华部分品类反倾销 | 待查 |
| 印度 | 对华 T 恤 / 家电 | 是否在征 |
| 泰国 | 对华热轧钢等 | 与本产品品类是否相关 |

**交付要求**：国家、HS 前缀、计征方式（从价% / 每平方米 / 每公斤）、税率、案件号、立案与终裁日期、是否含保证金与终裁两档、豁免企业清单。

## 七、如果只能做一件事

**补 P0-1 的清关杂费。**

理由：它是唯一一个「44 个市场全部缺失、且报告完全不提示」的项。其他缺口，系统至少会在报告的"置信度与缺口汇总"里说一句；这一项连说都不说，用户会拿着偏低的到岸成本去报价。

欧盟 27 国差异小，可以先给一个"欧盟通用包"（报关代理费 + 码头费），东盟 6 国各给一份。这样一天之内就能让 33 个市场的到岸成本从"确定偏低"变成"可信"。
