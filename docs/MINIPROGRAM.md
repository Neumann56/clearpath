# 通途 · 手机端与小程序

> 两种形态，同一套接口与同一套规矩。
> **H5 现在就能用；微信小程序要导入开发者工具才能跑，且有域名硬门槛。**

---

## 一、先看 H5（30 秒）

浏览器直接开：

```
http://47.123.4.136:8080/m          ← 线上（需重新部署后才有，见第六节）
http://127.0.0.1:4173/m             ← 本地
```

手机上打开就是小程序的样子：底部五个 tab、单列卡片、数字不折行。
**发微信给别人也能直接开**，不用装任何东西。比赛演示用这个最稳。

---

## 二、导入微信小程序（5 分钟）

1. 装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 目录选：

   ```
   通途_app/miniprogram
   ```

3. AppID 选「**测试号**」（没有小程序账号也能跑全部功能）
4. **右上角「详情」→「本地设置」→ 勾上「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**

   ⚠️ 这一步不做，所有请求都会失败，而且报错只写一句 `request:fail url not in domain list`，看不出是域名问题。

5. 看一眼 `miniprogram/config.js`。**整包只有这一个文件决定数据从哪儿来**：

   ```js
   const MODE = 'direct';                              // direct / proxy / mock
   const BASE_URL = 'http://47.123.4.136:8080';        // 手机和电脑同一 WiFi 时可换局域网 IP
   const CLOUD = { envId: '', fn: 'apiProxy' };        // 只有 MODE = 'proxy' 时才读
   ```

6. 点「编译」。看到首页两个数就通了。

> 想验证代码有没有被改坏：`node scripts/check-miniprogram.js` 和 `node scripts/test-miniprogram.js`（需先起服务）。

## 三、域名这件事必须说清

微信小程序正式版的请求要求：**https + 已备案域名 + 在后台配置 request 合法域名**。
`http://47.123.4.136:8080` 一条都不满足。

但这条白名单**只管小程序自己发起的请求**，不管云函数。所以有两条路：

| 做法 | 备案 | 多久能让陌生人用 | 怎么做 |
| --- | --- | --- | --- |
| `MODE = 'proxy'` 走云函数 | **不用** | 半天 | 见下面「四、云函数通道」 |
| `MODE = 'direct'` 直连 | 要 | 7–20 工作日 | 买域名 → ICP 备案 → 配 https → 后台配 request 合法域名 |

按场景看：

| 场景 | 能不能跑 | 怎么做 |
| --- | --- | --- |
| 开发者工具模拟器 | ✅ | 勾上第二节第 4 步即可 |
| 真机预览（调试模式） | ✅ | 扫码选「**调试**」而不是「预览」，手机上开调试模式 |
| 真机体验版 / 正式版 | ✅ | **必须** `MODE = 'proxy'` |
| 正式发布 | ✅ | 同上一行，`proxy` 档不需要备案 |

**结论：比赛当天用 `proxy` 档最稳，投屏也行，扫码给别人用也行。**

## 四、云函数通道（免备案那条路）

四个动作，十分钟：

1. 开发者工具左上角点「云开发」→ 开通 → 复制**环境 ID**
2. 打开 `config.js`：`MODE` 改成 `'proxy'`，`CLOUD.envId` 填上那个 ID
3. 右键 `miniprogram/cloudfunctions/apiProxy` → **上传并部署：云端安装依赖**
4. 进云开发控制台 → 云函数 → apiProxy → 配置 → **超时时间从 3 秒改成 60 秒**

第 4 步最容易漏。默认 3 秒，普通接口够用，但老周问一句话要 10–20 秒，不改一定超时，而且报错只写 `errCode: -1`。

云函数里做了三件保护，改代码时别拆掉：

- **路径白名单**只放 `/api/`，不写白名单它就是个对外开放的转发器
- 拦 `..` 路径穿越，不接收完整 URL（只收 path）
- 后端不可达时返 502 并带原因，不抛异常

改完跑一次：`node scripts/test-cloudfn.js`（会真打本机后端，15 项）。

## 四、页面怎么组织的

底部五个 tab，和 PC 的七个菜单不是一一对应——手机上装不下那么多入口。

| tab | 干什么 | 和 PC 的差别 |
| --- | --- | --- |
| 首页 | 一句话录入 + 双口径样例 + 三个入口 | 少了长文说明，多了实时样例数字 |
| 预演 | 七项必填 + 底部实时估算 | 高级项默认折叠，国家改成底部弹层分组 |
| 历史 | 本设备的报告列表 | 卡片式，带状态色点 |
| 看懂 | 13 条视频，按「先看哪条」排序 | **点卡片复制链接**，小程序放不了 B 站播放器 |
| 老周 | AI 助手 | 流式逐字显示，走服务端 `/.cloud/` 转发 |

非 tab 页：报告详情、政策日历。

### 报告页的顺序是刻意反过来的

PC 版先摆成本表格再讲结论；手机版**先给两个数，明细全部折叠**：

```
① 钱是怎么算出来的      ← 展开
② 还没算准的            ← 展开（空的时候写「本票没有待核项」，不许不显示）
③ 要办的事              ← 收起
④ 别的可能（最坏值/敏感度/假设）
⑤ 时间节点
```

第 ② 组默认展开是硬规定：**空白会让人以为是没做**。

## 五、三条不能破的规矩（和小程序无关，但手机端更容易犯）

1. **真实成本 ≠ 需备现金**，永远两格并排，中间写「两个数永不相加」
2. **算不出来就写「—」加原因**，不写 0（`blocked` / `needs_confirmation` 时这是正常状态）
3. **老周不给金额**，只转述系统算好的数，且必须带出处

## 七、验证与回归

```bash
node scripts/check-miniprogram.js   # 静态：文件齐、组件解析、事件有实现、wx:key、语法、体积、模式自检
node scripts/test-miniprogram.js    # 逻辑：模拟 wx 运行时跑七个页面，连真实后端（47 项）
node scripts/test-cloudfn.js        # 云函数：白名单、转发、设备号隔离、502 兜底（15 项）
node scripts/mobile-shots.js        # 视觉：390px 截图 + 折行/遮挡检查（H5 版）
node scripts/verify.js              # 全量基线（202 项 + 文案门禁 + 性能）
```

`test-miniprogram.js` 抓过三个只有真跑才现形的问题：

- `config.js` 写成 `export`，小程序报 `Unexpected token 'export'` 且白屏不给行号
- 历史列表永远空——因为幂等缓存没带设备号，B 拿到 A 的报告 ID 但列表里没有
- 同一份报告出现两条「关税」时 `wx:key` 撞车，行错位

`mobile-shots.js` 抓过一个：底部提交条和 tabBar 都写 `bottom:0`，
主按钮被压在导航栏下面，**看着在、点不到**。

`check-miniprogram.js` 里有两条是防"静默出事"的：`MODE = 'proxy'` 但 `envId` 是空的
（真机一条请求都发不出去），以及 `MODE = 'mock'` 忘了改回去（所有人都看到样例数字）。

## 八、已知限制（写在明处，不装）

| 限制 | 原因 | 现在怎么办 |
| --- | --- | --- |
| 小程序放不了 B 站播放器 | 没有 iframe，web-view 要备案 | 点卡片复制链接去浏览器 |
| 老周不能拍照回填 | 图片识别那套逻辑在 PC 端，体积大 | 提示「图片识别在电脑版」 |
| 不能批量试算 | 要传 CSV，手机没有文件入口 | 走 PC |
| 报告不能导出 PDF | 同上 | 复制报告地址到电脑打印 |
| `proxy` 档老周没打字机效果 | `callFunction` 是一问一答，没有 SSE 通道 | 停顿后整段出现，界面不假装在流式 |
| `proxy` 档多一跳延迟 | 多了云函数这一次调用 | 国内实测 +60~150ms，可接受 |
| 断网只能演示 | 数据在服务端 | 自动切 `mock` / 样例单 + 页顶标注 |
