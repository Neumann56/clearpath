# 看懂外贸（视频栏目）

> 页路径 `/learn`｜内容 `data/content/videos.json`｜渲染 `lib/learn.js` + `lib/render.js: learnPage`
> 交互 `public/js/learn.js`｜回归 `node scripts/e2e-learn.js`｜失效检查 `node scripts/check-videos.js`

## 为什么有这个栏目

FOB、CIF 这些术语，用户看不懂就没法判断报告里的两个数是怎么回事：录入页让他填"货值"，
他心里想的却是合同上的 CIF 总价。术语不清，后面所有数字都是错的前提。

自己做一遍讲解视频不划算，也不诚实——讲得不如做外贸的人清楚。所以挑公开的、讲得对的，
按"看哪条、先看哪条"排好，并**说清楚它和这票货的关系**。这是栏目存在的唯一理由，
也是选片标准：**跟你要算的这票没关系的内容，再火也不收。**

## 三条产品口径（改这个栏目之前先读）

1. **视频给框架，参数给数。** 页面上明写：视频里的税率、时限、费用只能当背景。报告里每个数字
   带出处、置信度、适用日期。两边冲突时以报关行确认为准。不允许出现"按视频里说的算"这类暗示。
2. **不预加载播放器。** 13 个第三方 iframe 会毁掉首屏，也让断网演示变成一片白。点开才插入，
   同一时刻只留一个。
3. **不搬内容，只排序。** 不下载、不转存、不二创视频本身。卡片上是作者名 + 原站链接，
   页面底部写明版权归原作者、不代表作者为本工具背书。

## 加一条视频

1. 查 `bvid`（分享链接里 `BV` 开头那 11 位），用平台接口确认**能打开**：
   ```
   curl -A "Mozilla/5.0" "https://api.bilibili.com/x/web-interface/view?bvid=BVxxxxxxxxxx"
   ```
   `code: 0` 才算数；`state` 不是 0、`copyright` 不是 1（自制）的不要收。
2. 在 `videos.json` 的 `videos` 里加一条，字段：

   | 字段 | 说明 |
   | --- | --- |
   | `id` | 短横线命名，页面锚点与去重都用它，**不许改已有的** |
   | `bvid` | 平台编号，必须唯一 |
   | `title` | 展示标题。可以改写（去竖线、统一标点），但**不许夸大**、不许加"权威""必看" |
   | `author` / `mid` | 作者名与 UID，原值，用于注明出处 |
   | `seconds` | 时长秒数，原值（`scripts/check-videos.js` 会比对，差 2 秒以上报警） |
   | `publishedAt` | 发布日 `YYYY-MM-DD` |
   | `cover` | 封面 `https://i0.hdslb.com/bfs/archive/xxx.jpg`，**必须 https** |
   | `group` | `price` / `ship` / `money` 之一 |
   | `featured` | 每组最多一条，通栏展示，卡片上会标「建议先看这条」 |
   | `tags` | 2–4 个，展示用 |
   | `play` / `like` | 播放与点赞数，快照值 |
   | `takeaway` | **必填**。12–120 字，「看完能答上什么」。写不出这句，说明这条不该收 |
   | `hook` | 可为空串。跟**本产品**的关系；空串表示有意留空，不能漏字段 |

3. 跑 `node --test tests/learn.test.js`（会检查编号重复、分组存在、每组条数、文案红线）。
4. 跑 `node scripts/e2e-learn.js --shot` 看一眼排版（封面没加载出来会立刻红）。
5. **重启服务**——内容在启动时读一次，不重启看不到改动。

## 常见的坑

- **封面必须 `referrerpolicy="no-referrer"`。** 哔哩哔哩图床对站外 Referer 返回 403，
  少了这个属性 13 张封面全是空的，而且浏览器不会报错。
  （验证：`curl -e "http://127.0.0.1:4173" <封面地址>` 返回 403，不带 `-e` 返回 200。）
- **每组至少 2 条。** 少于 2 条时，"每组一条通栏主课"的逻辑会把唯一那条吃掉，分组看着像空的。
- **每组最多 1 条 `featured`。** 多了会排出两块通栏，版面塌掉。测试钉住了这条。
- **改了 `videos.json` 不重启，页面不变。** 这是有意的：栏目是静态内容，不该每次请求都读盘。
- **`scripts/check-videos.js` 不进 `verify.js`。** 它要联网，而基线必须能断网跑。

## 文案红线

和报告同一套（`scripts/copy-lint.js` 的 W1–W7，`/learn` 已在扫描列表里）：

- 不许出现「包税」「保证清关」「一定能进」「保证通过」
- 不许把估算写成结论
- 不许出现内部字段名（`landedCost`、`cashRequired` 之类）
- 不许出现跨口径合计

栏目页是最容易破防的地方——人在看视频时不看免责声明，一句"这样报最省税"就会被记住。

## 老周怎么指路

`public/js/product-map.js` 里有一条 `learn` 入口：问到术语（FOB/CIF/Incoterms…）时，
他可以直接给 `[看懂外贸](/learn)` 这一个链接。`CHAT_LINK_RE` 已放行 `/learn`，
否则渲染层会因为白名单不通过而把它退化成纯文本。
