## 二、任务 A · 33 个市场的清关规费【本轮最高优先级】

### 2.1 背景

目前通途引擎中，以下 33 个市场的清关杂费**全部按 0 计算，且报告不作任何提示**。到岸成本在这些市场上系统性偏低（按行业水平约差货值的 0.3–0.8%），但用户完全看不出来。

上一轮已覆盖的市场：**欧盟 27 国**（通用包，含报关代理费 €80–200 + THC €50–150）和**东盟 6 国**（泰/越/马/印/菲/新）。本轮需要补齐其余 33 个市场。

### 2.2 待采集市场清单（按区域分组）

| 区域 | 国家 | 数量 | 优先级 | 采集要点 |
|---|---|---|---|---|
| **东亚** | 日本、韩国 | 2 | ⭐⭐⭐ 最高 | 日本：通关业者手数料（报关代理）量级；韩国：关税士报酬 |
| **南亚** | 印度、巴基斯坦、孟加拉国 | 3 | ⭐⭐⭐ 最高 | 印度：ICEGATE 系统费 + CHA 代理费（$100–250 量级需核实） |
| **欧洲非欧盟** | 英国、瑞士、挪威、塞尔维亚、乌克兰、俄罗斯 | 6 | ⭐⭐ 中 | 英/瑞士/挪威与欧盟近似可简化；俄罗斯延后（现况下出口极少） |
| **中东** | 沙特、阿联酋、土耳其、以色列、卡塔尔、科威特、阿曼、巴林 | 8 | ⭐⭐ 中 | 沙特 SABER 系统费已包含在认证成本，清关另计通关代理 + THC |
| **拉丁美洲** | 巴西、墨西哥、智利、哥伦比亚、秘鲁、阿根廷 | 6 | ⭐ 可延后 | 巴西 customs broker (Despachante Aduaneiro) 费用偏高，叠加 Siscomex 系统费 |
| **非洲** | 南非、尼日利亚、肯尼亚、埃及、摩洛哥、加纳、埃塞俄比亚、坦桑尼亚 | 8 | ⭐ 可延后 | 网络数据极少，**唯一可靠路径是当地报关行直接报价** |
| **合计** | | **33** | | |

### 2.3 每个市场需要采集的字段

按需求书 v1.0 第四章表格式：

| 字段 | 说明 | 示例（美国） |
|---|---|---|
| 规费名称 | 当地官方名称，中文与原文 | 商品处理费 Merchandise Processing Fee |
| 计算方式 | 从价百分比 / 每票固定 / 从量 / 阶梯 | 从价 0.3464% |
| 上下限 | 有最低、最高金额的必须标 | 最低 $33.58 / 最高 $651.50 |
| 计费基数 | CIF / FOB / 申报货值 / 运费 | 申报货值 |
| 是否计入完税价格 | 影响关税基数 | 否 |
| 生效日期 | 费率会调整，必须可追溯 | 以官方公告为准 |
| 官方链接 | 能点开看到该条规定的页面 | 海关与边境保护局官网 |

### 2.4 重要提醒

- **这项数据网络调研基本填不了**。百运网等物流平台的汇总数据精度为"量级参考"，不适合入库到计税引擎。
- **最可靠的路径：联系各目标市场的报关行/货代，索取实际报价单**。哪怕每个市场只拿到一家的报价，也比"按 0 计算"强两个数量级。
- 若某个市场实在拿不到报价，请按"行业通用水平"给出区间并标注为**估算**，引擎侧会将其纳入"置信度与缺口汇总"，不会静默当零处理。

## 三、任务 B · RCEP 逐年降税表（日本 + 韩国方向）

### 3.1 背景

RCEP 框架下，日本和韩国对中国产品的关税是**分年逐步降低**的（日本部分品目到第 16 年、韩国到第 10–20 年才降为零）。目前通途引擎中：
- 东盟方向的 ACFTA Form E 已有 3 个品类（汽配/笔电/手机）
- **日本、韩国方向的 RCEP 优惠税率完全空白（0 条）**

### 3.2 需要采集的内容

以下 6 个品类，对日本和韩国，查询 **RCEP 协定项下的逐年进口关税税率**：

| HS 编码 | 品类 | 日本方向关键问题 | 韩国方向关键问题 |
|---|---|---|---|
| 870891 | 汽车零件 | 日本汽配 MFN 已为 0%，确认 RCEP 是否仍有优惠（原产地规则便利化？） | 韩国汽配 MFN **8%**，RCEP 承诺降税路径（第几年降到多少） |
| 847130 | 笔记本电脑 | 日本 MFN 零关税，确认 RCEP 无额外优惠 | 韩国 MFN 可能零/低，确认 |
| 851713 | 智能手机 | 同上 | 同上 |
| 854143 | 光伏组件 | 日本 MFN 是否零？RCEP 有无额外降税 | — |
| 610910 | T 恤 | 日本对纺织品关税较高（MFN 可能 7–10%），RCEP 降税路径是重点 | 韩国纺织品 MFN 约 13%，RCEP 降税空间大 |
| 940360 | 木家具 | 日本 MFN 约为 0–3%，确认 | — |

### 3.3 每条数据需要的字段

| 字段 | 说明 |
|---|---|
| 协定名称 | RCEP |
| 原产地证书 | RCEP 原产地证明 |
| 基准年 | 降税起始年份（RCEP 生效年） |
| 逐年税率 | `[{year: 2026, rate: 0.05}, ...]` 直到降为零的年份 |
| 区域价值成分门槛 | 通常 RVC 40% |
| 官方来源 | 日本关税局/韩国关税厅的 RCEP 税率表链接 |

### 3.4 为什么值得做

以韩国汽配为例：MFN 8% vs RCEP 优惠 0%（最终年份），一票 $51,416 CIF 的货差 $4,113。即使还在降税过渡期（如 2026 年 RCEP 为 5%），差额也有 $1,542。这是真实存在、系统能输出、企业能省钱的数据——但前提是我们得先把这个表建出来。

## 四、任务 C · 瑞士纺织品从量税额档位

### 4.1 背景

瑞士对纺织品（HS 61/62 章，含 610910 T 恤）的进口关税不是按货值百分比，而是**从量计征：每公斤征收 CHF 0–5**。通途引擎目前的处理是：

- 参数中 `pending: true`，标记为"该品类不按百分比征"
- 引擎抛 `E_MFN_PENDING`，拒绝出数
- 报告显示"瑞士市场该品类税率未入库，无法计算"

这意味着 6 个品类中，瑞士 × 610910 这个组合目前**完全不可用**。

### 4.2 需要采集的内容

查询瑞士联邦海关（EZV / Tares）税则中，HS 610910（棉制 T 恤）的**从量税精确档位**：

| 问题 | 说明 |
|---|---|
| 有没有零税率档位？ | 即多少 CHF/kg 以下免税——如果有，正常商业出货（如 200g/件 × 5,000 件 = 1,000kg）是否落在免税区间内？ |
| 各档位的 CHF/kg 具体数值 | 不是"0–5"区间，而是实际税则上的分段（如 0–100kg: CHF 0, 101–1000kg: CHF 3, 1000kg+: CHF 5） |
| 是否有最低/最高征收额 | 部分从量税设有最低征收金额（如"不低于 CHF 10/票"） |
| 官方来源 | 瑞士联邦海关 EZV Tares 在线查询结果链接 |

### 4.3 为什么必须先做

- 瑞士是 44 个市场之一，但 610910 这个组合是该市场中**唯一**挂了 `pending` 的品类
- 其他 5 个品类（汽配/笔电/手机/光伏/木家具）瑞士 MFN 均为零关税，正常输出
- 只差这一个品类，瑞士就从"6/6 全通"变成"5/6 可用"——补齐后瑞士就是全市场覆盖

## 五、交付规范

### 5.1 交付方式

按**国家或区域整包**交付，不必等全部齐备。收件后我方入库校验并反馈问题，形成循环。

### 5.2 优先级排序

| 序号 | 任务 | 内容 | 投入 |
|---|---|---|---|
| 1 | 任务 A（部分） | **日韩 + 印度** 清关规费（5 国） | 找 5 家报关行报价 |
| 2 | 任务 C | **瑞士纺织品** 从量税额 | 查 EZV Tares，半小时 |
| 3 | 任务 B | **RCEP 日韩** 降税表 | 查日本关税局/韩国关税厅 |
| 4 | 任务 A（剩余） | **英/欧6/中东/拉美/非洲** 清关规费（28 国） | 逐批推进 |

### 5.3 质量要求

- **必须有一手链接**：能点开看到对应那一行
- **必须有生效日期**：税率会调整
- **口径必须写清**：从价还是从量、6 位还是 8 位
- **不确定就标待核**：标待核，引擎会将其排在"置信度与缺口汇总"里优先提示
- **给出量级区间而不是单点值**：若拿不到精确报价，用区间（如 $80–200/票）+ 标注"估算"（引擎侧会按"估算"入库"

## 六、对调研方的补充说明

### 任务 A（清关规费）为什么网络查不了：

- 每个国家的海关官方收费标准通常不单独列出"报关代理费"——这是报关行的商业行为
- 码头操作费（THC）随船公司/港口浮动，没有统一公开数据库
- 物流平台的汇总数据（如百运网）是量级参考，不能入库到计税引擎
- **建议路径**：通过各目标国的货代/报关行直接索取 B2B 整柜清关报价单。即使只有 1–2 家的报价，也比缺数据强。

### 任务 B（RCEP）的数据源：

- 日本：关税局 `customs.go.jp` → RCEP 税率表
- 韩国：关税厅 `customs.go.kr` → FTA 关税查询
- 中国商务部 FTA 服务网 `fta.mofcom.gov.cn` 也有 RCEP 逐年降税汇总

### 任务 C（瑞士纺织品）的数据源：

- 瑞士联邦海关 EZV：`xtares.admin.ch` → 输入 HS 610910 查询
- 结果直接截图 + 复制即可，不用翻译
