# 通途 CLEARPATH

> 进口到岸成本测算工具——报价前一算，把目的国关税、增值税、规费和隐性收费拆成两个数：真实成本、需备现金。算不准的标出来，不凑一个数字。

## 作品名称

**通途 CLEARPATH**

## 一句话简介

填货值、运费和目的国，算两个数：这批货到手花多少钱，报关那几天账上要备多少。算不准的会列出来，不硬凑一个数字。

---

## 项目简介

外贸报价最大的痛点不是"不知道关税多少"，而是**拿不准哪些钱必须算进去、哪些钱只是暂时垫出去**。比如 27% 的增值税能退回来，但必须先交给海关——把增值税当成本，毛利被虚减一半；当它不用备钱，接单后资金链断。

通途 CLEARPATH 做一件事：**分开算两个数**。

- **真实成本**：算毛利用的，扣掉了可退的增值税
- **需备现金**：报关那几天账上要压多少，包含了要垫的增值税

同时给一份**标了价的"算不准清单"**——哪些税率拿不准、缺什么资料、每一项值多少钱。不是"可能影响结果"这种模糊表述，而是标到美元的差额。

### 核心功能

| 页面 | 做什么 |
|---|---|
| 首页 | 自然语言输入这票货，3 秒出报告样例（样例数字是引擎实时算的，不是写死的） |
| 新预演 | 逐项填表单，实时校验差项，不等到提交才报错 |
| 报告（15 段） | 两个数 + 税链明细 + 待核清单 + 最坏值 + 出处置信度 + 双分支并列 |
| 政策日历 | 22 项税率/反倾销/232 措施变动的时间轴 |
| 市场热度 | UN Comtrade 真实进口数据：这个品类在目的国一年真进了多少钱 |
| 店铺入驻 | 10 个海外平台一步步的入驻指引（材料清单 + 步骤 + 注意事项） |
| 看懂外贸 | 13 条 FOB/CIF/DDP 讲解视频，按新手最适合先看的顺序排列 |
| 快速上手 | 三步从零到第一份报告 |
| 老周 AI | 干了十二年的外贸业务经理，右下角悬浮球全页面常驻 |

### 技术特点

- 零 npm 依赖（只用 Node.js 内置模块，断网可跑）
- 68 个市场 × 6 个品类 = 408 个可直接出数的组合
- 15 段固定报告结构，每条税率带出处链接和置信度
- 移动端 /m 独立模板（不是 PC 加媒体查询，信息顺序相反）
- 微信小程序完整包（`miniprogram/`，7 页 5 tab，零依赖 CJS）

## 使用方式

### 本地运行

```
解压 → 双击 start.bat
```

或手动：`node server.js`，浏览器打开 `http://localhost:4173`

系统要求：Node.js ≥ 20。无需安装任何 npm 包。

### 线上演示

> http://47.123.4.136:8080

（阿里云 ECS，2 核 4G Ubuntu 22.04）
